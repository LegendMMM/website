Wise Reconciliation App

This folder contains the full Next.js server app for shipment records, Wise transfers, approvals, and JPY settlement. GitHub Pages can only show this source entry page. The working app runs on Vercel with a Neon Postgres database.

Accounts Admin and partner login with password-based sessions.
Workflow Ledger entries require the other party's confirmation before settlement.
Settlement Confirmed entries are converted to JPY and settled once.

Local run:

cd websites/reconciliation-app && npm ci && npm run dev

Deployment details are in README.md. The Vercel production URL will replace this entry link after deployment.
