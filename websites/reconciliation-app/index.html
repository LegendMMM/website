Next.js app

雙方寄貨與 Wise 轉帳對帳工具

這個資料夾包含完整的 Next.js + Prisma + Postgres 對帳系統。它需要伺服器與資料庫， 因此 GitHub Pages 只能顯示這個入口頁；完整功能請用 Vercel 或本機開發伺服器執行。

帳號系統 管理員建立對方帳號，雙方登入後確認資料。
對帳流程 寄貨、轉帳、調整項目可互抵後產生 JPY 結算單。
Wise 估算 固定匯率、固定費、比例費與手續費分攤規則。

本機執行：

cd websites/reconciliation-app && npm install && npm run dev

詳細設定請看同資料夾的 README.md。
